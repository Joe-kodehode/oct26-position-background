CSS Position

This page shows the main position values in CSS.

Static

Static is the default. Elements stay in the normal page flow.

Static

Relative

Relative keeps the element in the normal flow, like static, but lets us move it with top, left bottom and right.

Relative

Absolute

Absolute moves an element relative to its nearest relative positioned parent. Absolute elements are taken completely out of the page flow.

Absolute
demo

Fixed

Fixed stays in the same position in the viewport, even when the page scrolls.

Look at the bottom right corner of the viewport.
Fixed

Sticky

Sticky acts like relative until it reaches a scroll position, then it sticks and acts like fixed.

Sticky
