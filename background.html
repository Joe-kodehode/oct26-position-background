CSS Background Properties

This page shows common background properties in CSS.

background-color

This changes the background color of an element.

background-color

background-image

This adds an image as the background of the element.

background-image

background-repeat

This controls whether the background image repeats. By default a background image will repeat both horizontally and vertically. We can remove this with background-repeat: no-repeat

background-repeat

background-size

This controls the size of the background-image.

background-size

background-position

This controls where the background image sits.

background-position

background-attachment

This fixes a background image so it stays in place when the page scrolls.

background-attachment

Scroll the page to see the paralax effect.

background shorthand

The shorthand lets us write several background properties in one line.

background shorthand
